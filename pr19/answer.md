Ответы на вопросы для самоконтроля
1. Что такое Node.js и в чём его преимущества для создания серверов?
Node.js — среда выполнения JavaScript на движке V8. Преимущества: неблокирующая асинхронная модель (event loop), высокая производительность на I/O-нагрузках, единый язык на клиенте и сервере, огромная экосистема npm.

2. Как создать простой HTTP-сервер в Node.js?
Подключить модуль http, вызвать http.createServer((req, res) => {...}) и запустить server.listen(PORT).

3. В чём разница между методами GET, POST, PUT и DELETE?
GET — получение данных, без тела запроса.
POST — создание ресурса, с телом.
PUT — полное обновление существующего ресурса.
DELETE — удаление ресурса.

4. Что такое middleware и для чего используется?
Промежуточные обработчики, которые выполняются последовательно до/после основного обработчика. Используются для логирования, парсинга тела, аутентификации, CORS, статики и т.д. Каждый middleware получает (req, res, next).

5. Как обрабатывать различные HTTP-методы для одного URL?
Проверять req.method внутри обработчика маршрута: if (pathname === '/api/users' && method === 'GET') {...} else if (... method === 'POST') {...}.

6. Что такое CORS и зачем нужны соответствующие заголовки?
CORS (Cross-Origin Resource Sharing) — механизм, разрешающий браузеру делать запросы к ресурсам другого источника (origin). Заголовки Access-Control-Allow-Origin, Access-Control-Allow-Methods, Access-Control-Allow-Headers сообщают браузеру, какие кросс-доменные запросы разрешены.

7. Как организовать чтение тела POST-запроса в Node.js?
Слушать события data и end у объекта req:
let body = '';
req.on('data', chunk => body += chunk);
req.on('end', () => { const data = JSON.parse(body); });
