Ответы на вопросы

1. В чем разница между функциональными и классовыми компонентами?
   Функциональные компоненты — это простые JS-функции, которые принимают props и возвращают JSX. С появлением хуков они стали основным стандартом. Классовые компоненты наследуются от `React.Component`, используют `this.state` и методы жизненного цикла. В современном React предпочтение отдается функциональным компонентам.

2. Что такое props и state?
   `props` (свойства) передаются в компонент извне (от родителя) и доступны только для чтения (immutable). `state` (состояние) — это внутренние данные компонента, которыми он управляет сам с помощью `setState` или хука `useState`.

3. Как работает поднятие состояния (lifting state up)?
   Это процесс перемещения состояния из дочернего компонента в ближайший общий родительский компонент. Это делается для того, чтобы несколько дочерних компонентов могли синхронизировать свои данные или реагировать на одни и те же изменения.

4. Какие методы жизненного цикла вы знаете?
   - `componentDidMount` (монтирование)
   - `componentDidUpdate` (обновление)
   - `componentWillUnmount` (размонтирование)
   - `shouldComponentUpdate` (оптимизация рендера)
   - `render` (обязательный метод).

5. Как работают хуки useState и useEffect?
   `useState` возвращает массив из текущего значения и функции для его обновления. `useEffect` используется для выполнения побочных эффектов (запросы к API, подписки, таймеры). Он принимает функцию и массив зависимостей.

6. Что такое ключи (keys) в React?
   `key` — это специальный строковый атрибут, который помогает React идентифицировать элементы в списке. Если ключи не указаны, React будет перерисовывать весь список целиком при его изменении, что сильно снижает производительность.

7. Как обрабатывать события в React?
   События в React называются в camelCase (например, `onClick` вместо `onclick`). В обработчик передается синтетическое событие React, которое оборачивает нативное. Для предотвращения поведения по умолчанию используется `e.preventDefault()`.

8. Что такое управляемые и неуправляемые компоненты?
   В управляемых компонентах (controlled) значение поля формы привязано к состоянию React (value + onChange). В неуправляемых (uncontrolled) данные хранятся в DOM, а доступ к ним осуществляется через `ref`.

9. Как работает контекст (Context) в React?
   Context позволяет передавать данные через дерево компонентов без необходимости вручную передавать props на каждом уровне (избегая "prop drilling"). Создается через `createContext`, а используется через `Provider` и `useContext`.

10. Какие преимущества дают кастомные хуки?
    Они позволяют выносить повторяющуюся логику (например, работу с формами, запросы к API, подписки) в отдельные функции. Это делает код чище, переиспользуемым и легче тестируемым.
