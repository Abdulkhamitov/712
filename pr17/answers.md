Ответы на вопросы

1. В чем разница между управляемыми и неуправляемыми компонентами в формах React?
   В управляемых компонентах значение поля (value) контролируется состоянием React (через `useState`), и любые изменения проходят через обработчик `onChange`. В неуправляемых компонентах данные хранятся непосредственно в DOM, а доступ к ним осуществляется через `ref` (например, `useRef`).

2. Когда следует использовать управляемые компоненты, а когда - неуправляемые?
   Управляемые лучше использовать, когда нужна мгновенная валидация, динамическое изменение других элементов в зависимости от ввода или сложная логика (например, формы регистрации). Неуправляемые подходят для простых форм (например, форма обратной связи), где нужно просто получить данные при отправке, а также при работе с файлами (`<input type="file">`).

3. Какие методы используются для обработки событий в формах React?
   Используются синтетические события React, такие как `onChange` (для ввода), `onSubmit` (для отправки формы), `onBlur` (потеря фокуса), `onFocus`.

4. Как обрабатывать несколько полей ввода с одним обработчиком?
   Использовать атрибут `name` у каждого поля. В обработчике `onChange` брать `e.target.name` как ключ и обновлять состояние с помощью вычисляемых свойств объекта: `setFormData({ ...formData, [e.target.name]: e.target.value })`.

5. Какие подходы к валидации форм в React вы знаете?
   - Встроенная HTML5-валидация (`required`, `type="email"` и т.д.).
   - Ручная валидация в обработчике `onSubmit` перед отправкой.
   - Валидация «на лету» в процессе ввода (`onChange`).
   - Использование сторонних библиотек (Formik, React Hook Form).

6. Как предотвратить стандартное поведение формы (перезагрузку страницы)?
   Вызвать метод `e.preventDefault()` внутри обработчика события `onSubmit`.

7. Что такое "поднятие состояния" (lifting state up) в контексте форм?
   Это паттерн, при котором состояние формы выносится из дочернего компонента в родительский. Родитель хранит состояние (данные) и передает его дочерним компонентам через `props`, а также передает функции для его изменения. Это позволяет синхронизировать данные между несколькими компонентами.
