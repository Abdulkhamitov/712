Ответы на вопросы

1. В чём преимущества Express.js по сравнению с чистым Node.js?
- Меньше шаблонного кода: маршрутизация и middleware «из коробки».
- Удобная работа с параметрами URL, query-параметрами и телом запроса.
- Большая экосистема middleware (cors, helmet, morgan, body-parser и др.).
- Централизованная обработка ошибок.
- Модульная структура через express.Router().
- Активное сообщество и документация.

2. Что такое middleware в Express.js и каков порядок их выполнения?
Middleware — функции вида `(req, res, next)`, которые выполняются последовательно в порядке регистрации. Каждая может:
- изменить req/res;
- завершить ответ (res.send, res.json);
- передать управление дальше через next().
Если middleware не вызывает next() и не завершает ответ — запрос «зависает».

3. Как организовать модульную структуру роутеров?
- Создать папку routes/.
- В каждом файле: const router = express.Router(); router.get(...); module.exports = router;.
- В app.js: app.use('/api/users', usersRouter);.
- Middleware, общие для роутера, подключать через router.use(...).

4. Какие методы роутинга поддерживает Express.js и для чего используются?
app.get, app.post, app.put, app.patch, app.delete, app.options, app.head, app.all, app.use.  
Они соответствуют HTTP-методам: получение, создание, полное обновление, частичное обновление, удаление, preflight-запросы, заголовки, «любой метод», подключение middleware/роутера.

5. Как обрабатывать параметры URL и query-параметры в Express?
- Параметры URL: объявить в маршруте router.get('/:id', ...), получить через req.params.id.
- Query-параметры: получить через req.query (например, req.query.role).
- Тело запроса: req.body (после express.json()).

6. В чём разница между app.use() и app.METHOD()?
- app.use(path?, fn) — подключает **middleware** для всех HTTP-методов и для путей, начинающихся с указанного префикса.
- app.METHOD(path, fn) (например, app.get) — обрабатывает конкретный HTTP-метод и точное совпадение маршрута (с учётом параметров).

7. Как организовать централизованную обработку ошибок?
Добавить в конец цепочки middleware **после всех роутов**:
```js
app.use((err, req, res, next) => {
  console.error(err.stack);
  res.status(500).json({ error: 'Внутренняя ошибка сервера' });
});

8. Что такое router.param() и для чего он используется?
router.param('id', handler) — специальный middleware, который выполняется один раз при наличии параметра :id в маршруте. Удобно для валидации/загрузки сущности по ID и сохранения результата в req (например, req.userId), чтобы не дублировать проверку в каждом обработчике.
