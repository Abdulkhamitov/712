Ответы на вопросы 

1. В чём разница между `Link` и `NavLink` в React Router?
Link — просто создаёт навигационную ссылку без перезагрузки страницы (SPA-навигация). Используется для перехода.
NavLink — то же самое, но автоматически получает класс/стили для активного состояния (по умолчанию `active`). Удобно для меню.

2. Как получить параметры из URL в компоненте?
Через хук useParams:
const { id } = useParams();
Если маршрут объявлен как /products/:id, то id будет содержать значение из URL.

3. Что такое программная навигация и как её реализовать?
Программная навигация — переход между страницами из кода (например, после отправки формы), а не по клику на ссылку.
Реализация через useNavigate:
const navigate = useNavigate();
navigate('/contact/success');
navigate(-1); // назад

4. Как передать данные между маршрутами?
Через state при навигации:
navigate('/contact/success', { state: { message: 'OK', formData } });
Получение в целевом компоненте через useLocation:
const location = useLocation();
const { message, formData } = location.state || {};
Альтернативы: query-параметры (useSearchParams), параметры URL (useParams), глобальное состояние (Context, Redux).

5. Что делает компонент Routes?
Routes — контейнер для набора маршрутов (Route). Он «выбирает» первый маршрут, который совпадает с текущим URL, и рендерит соответствующий компонент. В React Router v6 только Route внутри Routes участвуют в маршрутизации.

6. Как создать защищённый маршрут?
<Route
  path="/admin"
  element={
    <ProtectedRoute isAuthenticated={user !== null}>
      <AdminPage />
    </ProtectedRoute>
  }
/>

7. В чём разница между useNavigate и redirect?
useNavigate — хук для программной навигации внутри React-компонента (v6). Работает только в функциональных компонентах и возвращает функцию.
redirect — функция/утилита, используемая в загрузчиках (loaders/actions) React Router v6.4+ или в серверных компонентах. Она возвращает объект ответа, который «перехватывается» роутером.
